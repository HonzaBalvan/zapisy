PHP - tvorba obrázků

  • "základní kostra" obrázku: 
        Header("Content-Type: image/png");#možno použít jpg
    $im = ImageCreate(100, 30);
    $BG= ImageColorAllocate($im, 0, 0, 0);
    ImageFill($im, 0, 0, $BG);
    #kreslení bodů, čar, obdélníků, elips, textu atd. viz dále
    ImagePNG($im);#možno použít ImageJPG
    imagedestroy ( $im );
  • hlavičku, která říka že to bude obrázek nastavíme pomocí
    Header("Content-Type: image/span png"); anebo Header("Content-Type: image/jpeg");
    před tímto nesmí být žádný výpis ať už HTM nebo PHP
  • $img = ImageCreate(100, 30);
    vytvoří obrázek o příslušné velikosti (šířka, výška), $img funguje jako popisovač daného obrázku - kreslené elementy přiřazujeme tomuto popisovači
  • pro kreslení je nejdřív nutné "vytvořit" barvy, které budeme používat:
    $barva = ImageColorAllocate($img, R, G, B);
    R,G,B - složky barvy 0-255, když bysme chtěli používat barvy podobně jako v HTML tzn. 00-ff je možné použít funkci HexDec(); např. bílá
    $wh = ImageColorAllocate($im, 255, 255, 255);
    jedná se o tzv. aditivní míchání barev tj. 100% červené+100% zelené + 100% modré je bílá a nikoliv černá
    (pozn. to co známe např. z "míchání vodovek" je tzv. subtraktivní míchání barev tj. 100% červené+100% zelené + 100% modré je černá)
  • nejprve vytvoříme pozadí obrázku:
    ImageFill($im, 0, 0, $wh);
    2. a 3. parametr jsou souřadnice od kterých se začíná vyplňovat (obvykle 0,0)

Jendotlivé elementy obrázku

  • souřadnice jsou chápany takto:
    x zleva do prava
    y odshora dolů
  • šířka čáry v PiXelech imagesetthickness ($im, šířka);
  • styl čáry můžeme určit pomocí funkce imagesetstyle($im, $style);
    kde $style je pole kde každý prvek určuje jak bude barevný konkrétní pixel na čáře 
    $w = ImageColorAllocate($im, 255, 255, 255); #bila
$k = ImageColorAllocate($im, 0, 0, 0);       #cerna
$style=Array($k,$k,$k,$k,$k,$k,$w,$w,$w);
imagesetstyle($im, $styl);
    nastaví, že čáry se budou kreslit čárkovaně s dlouhou černou čárkou a krátkým bílým přerušením
  • jednotlivý bod:
    ImageSetPixel ($im, x, y, barva);
  • úsečka od [x1,y1] do [x2,y2]
    ImageLine ($im, x1, y1, x2, y2, barva);
  • obdélník [x1,y1] - levý horní roh; [x2,y2] - pravý dolní roh
    ImageRectangle($im, x1, y1, x2, y2, barva);
  • vyplněný obdélník:
    ImageFilledRectangle($im, x1, y1, x2, y2, barva);
  • mnohoúhelník:
    ImagePolygon($im, x1, y1, x2, y2, ...xn ,yn , n, barva);
    x1,y1, ..., xn, ynsouřadnice vrcholů mnohoúhelníku; jako předposlední parametr je počet vrcholů
    vrcholy je pohodlnější mít v poli např.:
    $vrcholy=Array(100, 100, 75, 100, 250, 75, 75, 175, 20, 190);
    ImagePolygon($im, $vrcholy, Count($vrcholy)/2, barva);
  • vyplněný mnohoúhelník:
    ImageFilledPolygon($im, $vrcholy, Count($vrcholy)/2, barva);
  • elipsa: ImageEllipse($im, stred_x, stred_y, a, b, barva);
    stred_x, stred_y jsou souřadnice středu elipsy
    a a b jsou dvojnásobky poloos
  • vyplněná elipsa:
    ImageFilledEllipse($im, stred_x, stred_y, a, b, barva);
  • výseč z elipsy:
    ImageArc($im, stred_x, stred_y, a, b, start, end, barva);
    výseč z elipsy se středem v [stred_x,stred_y];
    a a b jsou poloosy
    start a end je směr od kterého se začíná, resp. ve kterém
    se končí - ve stupních, orientace je po směru hodinových ručiček, 0o "směřuje" doprava
  • vyplněná výseč z elipsy:
    ImageFilledArc($im, stred_x, stred_y, a, b, start, end, barva, IMG_ARC_EDGED);
    má přidaný parametr IMG_ARC_EDGED
  • text do obrázku:
    ImageString($im, font, x, y, napis, barva);
    x a y pravý horní roh obdélníku opsaného obrázku
    font typ fontu 1-5
    napis vypsaný text
  • text vertikálně (zezdola nahoru):
    ImageStringUP($im, font, x, y, $napis, barva);

Příklad 1:

Header("Content-Type: image/png");
// obrázek 201x140px
$img = imagecreatetruecolor(201, 140);

// příprava barev
$black = ImageColorAllocate($img, 0, 0, 0);
$white = ImageColorAllocate($img, 255, 255, 255);
$blue  = ImageColorAllocate($img,   0,   0, 255);
//obrázek vyplním modrouo barvou
ImageFill($img, 0, 0, $blue);


//elipsa o středu 60, 70 "poloosách" 50 30
ImageArc($img, 60, 70, 100, 60,  0, 360, $black);
//cara 50,30-150,30 bilou barvou
ImageLine($img,50,30,150,30,$white);

//změním šířku čáry
ImagesetThickness ($img, 5);

//tlustá cara 50,110-150,110 bilou barvou
ImageLine($img,50,110,150,110,$white);

//vykreslení obrázku
Imagepng($img);

//uvolnění paměti
Imagedestroy($img);
die;

Čtvercová síť se zvýrazněným kliknutím

  • Vytvoříme skript s názvem ctverce.php, který vykreslí 15×15 čtverečků
  • Vytvoříme si obrázek 301×301px
  • Vytvoříme si pole $ctverec=Array(0,0,20,0,20,20,0,20,0,0); tj. čtverec 20×20px
  • Ve dvou do sebe vnořených cyklů ($i a $j = 0...301, v kroku po 20) vytvoříme čtvercovou síť
  • Vytvoříme skript klik.php, kde bude formulář s jediným prvkem a to "odesílacím" obrázkem
    <input type=image src=ctverce.php name=sit>
  • Při kliknutí na obrázek obdržíme souřadnice kliknutí v proměnných
    $x=$_POST["sit_x"]
a
$y=$_POST["sit_y"]
  • Tyto odeslané proměnné předáme pomocí metody GET skriptu ctverce.php tj.:
    ctverce.php?x=$x&y=$y
Skript ctverce.php upravíme tak, aby příslušný čtvereček, kam se kliklo obarvil na červeno

Kochova vločka

Kochova vločka vzniká postupně:

  • 1. přiblížení je rovnostranný trojúhelník tj. body A0,0=[0,0], A0,1=[1,0], A0,2=[1/2,sqrt(3)/2], tj. útvar, který má tři strany
  • 2. přiblížení je šesticípá hvězda. Tj. každou stranu trojúhelníka z 1.přiblížení rozdělíme na třetiny a nad prostřední třetinou vztyčíme rovnostranný trojúhelník o straně 1/3, tj útvar, který má 12 stran. Body A1,0...A1,11
  • v každém dalším přiblížení postupujeme stejně tj. vezmeme stranu útvaru z předchozího kroku, roztřetíme ji a nad prostřední třetinou vztyčíme rovnostranný trojúhelník
  • tento útvar vykreslíme pomocí PHP

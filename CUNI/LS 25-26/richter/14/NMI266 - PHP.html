PHP

PHP je programovací jazyk pro tvorbu aktivních HTML stránek, skriptování se děje na straně serveru. Uživatel nemůže vidět zdrojový kód skriptu (narozdíl od JavaScriptu).

Soubor s PHP skriptem má závaznou koncovku php - podle ní webový server pozná jak má daný soubor interpretovat. Příkazy php jsou uzavřeny do <?php a ?>. Příkazy jsou ukončeny středníkem.

  • proměnné jsou označeny znakem $. Proměnné je možné psát dovnitř uvozovek, případně uzavřít jméno do složených závorek print "ahoj ${jmeno}!" (když za vypsanou proměnnou nechci mezeru)
  • stejně jako v JavaScript nejsou rozeznávány typy proměnných
  • PHP funkce můžeme, co se velkých malých písmenek týče, psát libovolně print $a; je totéž co Print $a;
  • pro komentáře používáme znak #
  • jednoduchý příklad:

Základní funkce

  • výpis
    print "abc";
    nebo
    echo "abc";
  • operace s čísly:
    • + - * / % += *= -= %=
    • sin cos atan atan2( y, x) ...
    • DecBin() BinDec() DecHex() HexDec() Rad2Deg() Deg2Rad()
  • operace s řetězci:
    • . spojování řetězců
    • Strlen() SubStr(str, zac, delka); od 0, je-li zac<0, pak se to počítá od konce
    • StrTr(str, "ABC", "abc"); transformace "znak za znak"
    • PREG_match('/regexp/', $str); testování pomocí regulárních výrazů - vrací true/false
    • PREG_replace( '/regexp/', "nahrada", $str); náhrada pomocí regulárních výrazů - vrací zaměněný řetězec - původní zůstane beze změny
    • NL2BR($str); převod konců řádků \n na <br>
    • HTMLEntities($retezec); převod proměnné $retezec na správné HTML zobrazování např. < na &lt;
    • "hrátky" s proměnnými:
      $a="b";
      $b="c";
      $c="Nazdarek";
      echo $$$a;
       vypíše Nazdarek
  • pole, operace s poli:
    • pole se označují jako běžné proměnné pomocí $
    • definice pole $pole=Array(1,2,3,4);
    • k jednotlivým položkám přistupujeme indexem v hranatých závorkách $pole[0];
    • pokud se k řetězci "chováme" jako k poli, pak jsou jednotlivé znaky brány jako položky pole tj.:
      $text="Dnes je krasny den";
      print $text[2];
      vypíše e
    • počet položek pole:
      Count($pole);
    • tvorba pole rozsekáním řetězce podle určitého oddělovače:
      Explode("oddelovac", $str);
  • podmínky:
    if (){...}else if(){...}else{...}
  • cykly:
    • for ($i;$i<10;$i++){}
    • while () {}
    • do {} while ();
    • continue přeskočí zbylé příkazy v daném kroku
    • break ukončí celý cyklus
  • funkce
    function max($a,$b){
    if ($a>$b){return $a;}else{return $b;}
    }
  • datum/čas
    Date("formát");
    formát:
    • Y rok YYYY
    • y rok yy
    • m měsíc 01-12
    • w den v týdnu 1..7
    • d den v měsíci 1..31
    • z číslo dne v roce
    • H hodina 00-23
    • h hodina 01-12
    • i minuta 00-59
    • s vteřina 00-59
    • A dop/odp AM/PM
    např.: Date("d.m.Y H:i:s"); vrátí: 30.4.2014 13:05:00
    • př.
    print Date("d.m. Y - H:i:s")." tj.".time(); vypíše: 22.05. 2017 - 10:05:35 tj.1495440335
  • Funkce time() vrátí počet vteřin od 1.1.1970 tzv. timestamp
  • mktime($hodina,$minuta,$vteřina,$měsíc,$den,$rok) vrátí počet vteřin od 1.1.1970 pro příslušné datum
    př.
    <?php
$novyrok2017=mktime(12,00,00,1,1,2017);
$den=Date("w",$novyrok2017);
print $den;
?>

    Vypíše "6" tj. 1.1.2017 byl sobota
  • okamžité ukončení skriptu:
    die;
  • posílání e-mailu pomocí PHP
    $to="richter@karlin.mff.cuni.cz";
    $header="From: richter@karlin.mff.cuni.cz";
    $subject="predmet dopisu";
    $body="telo dopisu";

  • operace se soubory:
    • File_Exists test existence souboru (na soubor se odkazujeme v rámci systému tj. /usr/html/richter/soubor)
    • $lines=File(soubor); v poli $lines budou jednotlivé řádky daného souboru, jako "soubor" můžeme použít jednak odkaz v rámci systému, ale také www odkaz
    • $fp=FOpen($file, "jak"); $fp je popisovač (handler) daného souboru
      jak: "r","a","w"
    • $radek=FGetS($fp); - přečte jeden řádek z daného souboru
      while ($radek=FGetS($fp)){...} - postupně přečte všechny řádky ze souboru, když je na konci vrátí false
    • FWrite($fp,"řádek zapsaný do souboru"); - do souboru s popisovačem $fp zapíše jeden řádek
    • FClose($fp); - ukončení práce se souborem
  • čtení adresáře:
    $d=OpenDir("/usr/users/richter/public_html/doc/php");
    while (($soubor=ReadDir($d))){
    echo $soubor."<BR>"; }
  • vkládání souborů - např. s připravenými funkcemi:
    require(cosi); - když se zavolá několikrát na stejný soubor, tak se vloží jen poprvé
    include(cosi) - když se zavolá několikrát vloží se pokaždé
    • kopírování souborů
    copy($co,$kam);
    funkce vrací true/false podle toho zda se kopírování zdařilo či ne.
